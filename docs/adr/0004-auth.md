# ADR 0004: Self-built auth in Go, Firebase only for SMS verification

- Status: Accepted (2026-11-13)

## Context

Clients sign up with email + mobile OTP, need owner approval, reset passwords and unlock with biometrics. Budget is ₹0; the owner wants backend depth on the resume.

## Decision

Go implements users, Argon2id password hashing, short-lived access tokens (JWT, 15 min) and rotating device-bound refresh tokens, lockout, and admin TOTP. Email OTPs go through Brevo/Resend. Mobile numbers are verified with Firebase phone auth on the client; the API verifies the Firebase ID token and marks the number verified. Biometric unlock protects the refresh token in the device secure store.

## Consequences

No auth vendor lock-in or MAU pricing; SMS stays within Firebase's free daily quota at this scale. We own security-critical code, so `internal/auth` PRs always need owner approval and security review.
